# Changelog

## 0.1.0 — 2026-09-07

- API de partes de trabajo sobre componentes Symfony 7.2 y SQLite.
- Login JWT HS256 (15 min) y refresh en cookie HttpOnly / SameSite=Strict.
- Rate limit de login, CORS por allowlist y cabeceras de seguridad.
- SPA React 18 (Vite): listado, alta y cambio de estado. Token de acceso solo en memoria.
- PHPUnit (hash, JWT, throttle, autorización) y Vitest (almacén de token, enum de estado).
